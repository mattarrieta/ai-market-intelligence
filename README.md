# AI Market Intelligence

AI Market Intelligence is a real-time prediction-market surveillance platform. It will ingest market data, detect unusual price, volume, and liquidity events, and generate evidence-grounded AI incident reports.

## Initial milestone

The first release will provide:

- Kalshi public market-data ingestion
- Exchange-independent market models
- Historical market snapshots
- Deterministic price and volume anomaly detection
- A FastAPI service and simple monitoring dashboard

The platform is designed to evolve toward Kafka-based streaming, event-time processing with Apache Flink, AI investigation through Amazon Bedrock, and deployment on AWS.

Project initialization in progress.
